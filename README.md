# Sales Team Traffic Light

Five score-sheet DocTypes (module **Sales Traffic Light**): BDE, ASM, Home Care, Inshop and Gallery.
Each sheet lists the active employees of the matching designation(s), with Branch taken from the Employee master;
scores for all employees are entered and submitted at once.

    bench get-app https://github.com/Ashwin-ABB/Sales-Traffic-Light
    bench --site <site> install-app sales_traffic_light
